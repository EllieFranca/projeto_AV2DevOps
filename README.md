# 📚 Sistema de Gerenciamento de Biblioteca



## Descrição



O Sistema de Gerenciamento de Biblioteca é uma aplicação desenvolvida utilizando Python, Flask e SQLite para gerenciar livros de uma biblioteca.



A aplicação permite cadastrar, visualizar, editar e remover livros do acervo.



## Tecnologias Utilizadas



- Python

- Flask

- SQLite

- Docker

- Git

- GitHub

- HTML

- CSS



## Guia de Instalação



### Clonar o repositório



```bash

git clone URL\_DO\_REPOSITORIO

```



### Entrar na pasta do projeto



```bash

cd projeto\_AV2DevOps

```



### Construir a imagem Docker



```bash

docker build -t projeto-av2-devops .

```



### Executar o container



```bash

docker run -p 5000:5000 projeto-av2-devops

```



### Inicializar o banco de dados



```bash

docker exec -it NOME\_DO\_CONTAINER python app/init\_db.py

```



### Acessar a aplicação



```

http://localhost:5000

```
